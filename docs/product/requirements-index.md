# Requirements index

> **Source:** DigiMenu TN requirements v0.2 (14 Oct 2026) and addendum v0.3 (17 Oct 2026, certificates). **Updated:** 21 Oct 2026.
> This page keeps the requirement **IDs**, where each one is built and when. For planned work, the acceptance criteria are in the matching GitHub issue.

## How to read this page

- **IDs:** `US-xx` user story · `C-xx` core feature (every café) · `M-xx` optional module (switched on per café) · `MOD-xx` modularity and versioning rule · `NFR-xx` non-functional requirement · `P-01` project tool (certificates).
- **Priority** is MoSCoW relative to **go-live** (the release installed at the pilot cafés, 23 Nov to 4 Dec). `*` means the module is built in the toolkit, and each café decides whether to switch it on. "v1.1" means decided, but built after go-live.
- **Milestone** is the sprint in which the item is done (GitHub milestones S1 to S7). `S1 → S3` means: first version in S1, finished in S3. "After go-live" items have no milestone yet.
- **Status:** every item is `Planned` today. The status changes to `In progress`, `Done` or `Live` as issues close.
- **Issue** is the title of the backlog issue that delivers it.

## 7. Out of scope

Not built for go-live: online payment, customer logins, SMS, Telegram, till or printer integration, stock management, native apps, delivery logistics, automatic translation without human review. See the [roadmap](roadmap.md#not-planned-for-go-live).
